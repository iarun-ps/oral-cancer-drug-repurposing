# Mock Pipeline Data

All files in this folder contain synthetic test data.

- oral_signature.csv: Simulated disease signature.
- candidate_drugs.csv: Simulated drug candidates.
- binding_scores.csv: Simulated binding predictions.

Drug names, identifiers, scores and drug-target relationships are fictional.
SMILES are valid molecular structures for testing RDKit.

These files are for testing only and must not be reported as scientific results.

Mock binding affinities represent illustrative pKd values.
Higher values indicate stronger predicted binding.
